# Sync Troubleshooting

## Files are not syncing

First check the desktop app's status icon. If it shows "Paused", click it and choose "Resume sync". Make sure you have a working internet connection and enough free space on your Nimbus Drive plan. Restarting the desktop app solves most temporary sync problems.

## Supported systems

The desktop app supports Windows 10 and 11, macOS 13 or later, and Ubuntu 22.04 or later. Mobile apps are available for iOS 16+ and Android 10+.

## File size limits

The maximum size for a single file is 50 GB when uploaded with the desktop app and 5 GB when uploaded through the web browser. Larger files must be split before uploading.

## Conflicted copies

If the same file is edited on two devices while offline, Nimbus Drive keeps both versions. The second one is saved as "filename (conflicted copy).ext" next to the original, so no changes are lost.

## Recovering deleted files and old versions

Deleted files stay in Trash for 30 days on the Free plan and 180 days on Pro and Team plans. To restore a previous version of a file, right-click it and choose "Version history". Pro and Team plans keep 180 days of version history; the Free plan keeps 30 days.

## Selective sync

To save disk space, open the desktop app settings, go to Selective sync, and untick the folders you do not need on that computer. They stay in the cloud and remain available on the web.
